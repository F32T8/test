Updated: 2024-12-17 File Size: 14kb freecigs@proton.me — — — — — — # NAVIGATION Use Ctrl + F to search "#" for site sections. — — — — — — # ABOUT age:36 | pro:he/him | loc:usa | bld:a+ FREECIGS.org is a semi-anonymous journal and a dumping ground for ideas, lists, and other texts. Broadcasting from a suburb in the heart of America. Started in December 2024. The site's content will likely center around personal computing, digital minimalism, anti-capitalism, video games, horror movies, skepticism, and graphic design. This site is (mostly) plain text. There's a bit of HTML/CSS to wrap the text, make the line height a little more comfortable, and allow for dark mode. The goal is to keep things as simple as possible and to work within restraints. Largely inspired by textonly.website (which is maintained by koray.er), minim.blog, divacorp.net, and the idea of keeping a digital journal using a .txt file. Lastly, this site should not be discoverable via search engines and has a robots.txt file that blocks (or discourages) crawlers. The only way anyone should be able to find this site is via a direct link or through textonly.website. — — — — — — MORE COMING SOON
